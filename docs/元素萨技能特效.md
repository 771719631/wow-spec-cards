这套元素萨的特效，关键不是让每个技能都“满屏爆炸”，而是形成非常清晰的三种元素节奏：

> **雷电要快，大地要重，火焰要爆；升腾要有变身与爆发感。**

而且要让玩家在混乱的群体伤害中，仍然能分清：

- 哪次伤害来自闪电链；
- 哪三次伤害来自地震术；
- 哪一轮火球是“根深蒂固”触发；
- 当前是否处于“升腾过载”。

---

# 一、元素萨统一特效语言

|元素|主要颜色|动态特征|声音感觉|
|---|---|---|---|
|雷电|青蓝、银白、电紫|迅速、分叉、瞬间穿透|电流炸裂、尖锐雷鸣|
|大地|土黄、暗金、岩灰|沉重、震荡、碎裂|低频轰鸣、石块碰撞|
|火焰|橙红、炽白、熔金|爆发、扩散、灼烧|火焰喷发、空气爆裂|
|升腾|蓝白雷霆＋橙金火焰|变身、悬浮、元素融合|雷鸣、火焰、低沉吟唱|

在你现在的月夜庭院战场里，这三种颜色辨识度很好：

- 蓝色雷电会与夜色融合，但银白核心可以保证清晰；
- 土金色地震会突出地面阵法；
- 橙红火球会成为最亮的爆发层。

# 二、闪电链

技能效果：

> 对敌方全体造成10点伤害，回复1点技能点。

## 核心表现

不要做成五道雷同时从天上落下，那样更像“雷暴术”。

推荐设计为：

> **一道主闪电命中首个敌人，然后连续分叉、跳跃至其他敌人。**

这样“链”这个概念才清楚。

## 完整动画流程

### 1. 元素蓄力，约0.15秒

当前元素萨角色：

- 角色卡向上浮起约10px；
- 双手或武器之间出现一颗青蓝色电球；
- 头发和衣摆被静电轻轻抬起；
- 脚下出现一圈快速旋转的雷纹；
- 周围生成细小电弧。

此时敌方五名角色边缘出现非常淡的蓝色轮廓，提示这是全体攻击。

### 2. 主雷命中，约0.10秒

第一道粗大的银白雷电击中敌方中间角色：

```
元素萨
  ↓
敌方中心目标
```

雷电结构分三层：

1. 中心为近乎纯白的高亮电芯；
2. 外围是青蓝色电光；
3. 最外层带少量紫色细弧。

主雷命中时：

- 目标瞬间闪白；
- 血条下方出现电流跳动；
- 卡牌快速抖动一次；
- 地面产生一个蓝白色圆形电纹。

### 3. 闪电跳跃，约0.25秒

主雷命中后，电流快速分叉：

```
中心目标
├── 左侧目标1
├── 左侧目标2
├── 右侧目标1
└── 右侧目标2
```

不要五个目标完全同时亮起，可以采用约40～60毫秒的跳跃延迟：

```
中心 → 左一 → 右一 → 左二 → 右二
```

这样玩家能看出闪电正在传播。

每跳跃一次：

- 产生一声较轻的电流爆响；
- 目标边缘出现蓝白电弧；
- 飘出青蓝色伤害数字：

```
-10
```

### 4. 回复技能点，约0.18秒

最后一个目标被击中后，所有残余电流向中央聚合成一颗蓝白色雷珠。

雷珠从敌方区域飞回技能点栏：

```
敌方阵列
→ 雷珠飞回
→ 点亮一颗技能点
```

例如：

```
3/8 → 4/8
```

回复时：

- 空的技能点槽被雷电点亮；
- 出现一圈很小的银白电环；
- 播放清脆的能量充能声。

## 镜头反馈

- 主雷命中时，战场画布震动约4px；
- 电流跳跃期间，不重复震屏；
- 最后一个目标命中时再轻震一次；
- HTML界面和技能按钮保持固定。

## 总时长

正常速度约：

**0.65～0.8秒**

二倍速约：

**0.38～0.45秒**

# 三、根深蒂固

技能效果：

> 被动：每次释放技能有20%几率触发升腾，对敌方全体发射火球，造成12点伤害。

这是被动技能，不能每次都播放很长的施法演出，否则会拖慢所有技能。

它需要做到：

> **触发时非常惊喜，但演出必须短促。**

## 常驻表现

在元素萨角色脚下，常驻一个非常淡的“大地根脉纹章”：

- 暗金色树根状纹路；
- 平时亮度很低；
- 只有释放技能时才短暂闪烁；
- 被动图标下方不显示冷却，只显示一个小型概率符号。

这可以把“根深蒂固”与后面的火球联系起来：

> 大地根脉吸收元素能量，最终引燃升腾之火。

## 未触发时

每次元素萨释放完一个技能：

- 脚下根脉纹章快速亮一下；
- 随即熄灭；
- 不弹出“未触发”文字；
- 整个反馈控制在0.1秒以内。

这样玩家能隐约感知系统进行过判定，但不会被失败信息打扰。

## 触发时

### 1. 被动唤醒，约0.12秒

主技能完成主要命中后：

- 元素萨脚下的暗金根脉突然向外扩散；
- 地面裂缝中涌出橙红色光芒；
- 被动技能图标快速放大并闪现金色边框；
- 角色上方出现小型毛笔字：

```
根深蒂固
```

文字只停留约0.4秒，不要占满画面。

### 2. 火焰元素出现，约0.15秒

元素萨背后展开一道半透明的橙金色元素裂隙。

裂隙中生成五颗小型火球：

- 火球中心为炽白；
- 中层为金黄色；
- 外层为橙红火焰；
- 后方带少量黑色烟尾；
- 大小略有不同，避免机械排列。

### 3. 全体火球追击，约0.25秒

五颗火球分别锁定五名敌人：

```
火球1 → 敌方1
火球2 → 敌方2
火球3 → 敌方3
火球4 → 敌方4
火球5 → 敌方5
```

飞行路径采用轻微弧线，不要直线平移。

命中时：

- 目标位置出现小型橙红爆炸；
- 火焰向外翻卷；
- 飘出橙色数字：

```
-12
```

- 敌方卡牌边缘短暂出现灼烧效果。

## 与主动技能的衔接

被动火球不要和主技能同时完全重叠。

推荐顺序：

```
主技能命中
→ 等待80～120ms
→ 根深蒂固亮起
→ 火球追击
```

例如闪电链触发时：

```
青蓝闪电结束
→ 地面根脉变红
→ 橙色火球追击
```

冷暖色转换会非常明显。

## 总时长

附加演出约：

**0.5～0.65秒**

它是附加攻击，不需要全屏暗化，也不要使用强烈镜头拉近。

# 四、地震术

技能效果：

> 消耗2点技能点，对敌方全体造成3次7点伤害。

这是一个持续多段群攻技能，重点是：

> 三次震动必须有明显的递进，而不是同一段动画重复三遍。

## 完整动画流程

### 1. 消耗技能点，约0.15秒

两颗技能点从资源栏飞向“地震术”按钮：

```
技能点 ×2
→ 地震术图标
→ 化为土黄色碎光
```

例如：

```
3/8 → 1/8
```

### 2. 大地预警，约0.25秒

敌方全体脚下出现一个宽大的土金色法阵：

- 法阵覆盖敌方阵列，而不是每人单独一个；
- 圆环中有岩石纹、裂缝纹和古老符号；
- 地面先轻微震动；
- 小石子慢慢浮起；
- 敌方角色脚下出现淡黄色警告光。

这一阶段让玩家知道大攻击即将发生。

---

## 第一次震击：裂纹

持续约0.2秒。

- 地面产生第一圈裂纹；
- 少量石屑弹起；
- 敌方角色轻微上下震动；
- 每名敌人飘出：

```
-7
```

伤害数字使用暗黄色。

镜头震动幅度约4px。

---

## 第二次震击：岩石隆起

间隔约0.18秒。

- 裂纹进一步扩散；
- 数块岩石从地下向上顶起；
- 尘土形成环形扩散；
- 敌方角色向上弹起一点；
- 再次飘出：

```
-7
```

镜头震动幅度提升到7px。

---

## 第三次震击：大地爆发

间隔约0.18秒。

- 中央地面向上爆裂；
- 大块岩石、尘土与金色冲击波同时出现；
- 原本悬浮的小石子全部被震飞；
- 敌方角色产生最明显的受击动作；
- 第三次飘出：

```
-7
```

最后一段数字比前两次稍大。

镜头震动幅度约10～12px，并伴随短暂的低频冲击。

## 伤害数字避免混乱

五名敌人、每人三次伤害，一共会出现15个数字，容易遮挡画面。

推荐让每个角色的数字固定在自己的血条上方，并垂直轻微叠放：

```
-7
-7
-7
```

或者依次替换：

```
第一次：-7
第二次：-7
第三次：-7
结束后短暂显示：共计 -21
```

不建议直接只显示“-21”，因为这个技能的三段攻击可能与护盾、醉拳、被动触发等机制有关。

## 地震结束

- 岩石落回地面；
- 裂纹中的金光逐渐熄灭；
- 尘雾停留约0.4秒后消散；
- 地面恢复原状。

## 总时长

约：

**1.05～1.25秒**

二倍速约：

**0.6～0.7秒**

# 五、升腾

技能效果：

> 消耗3点技能点，对敌方全体发射火球造成16点伤害，并获得“升腾过载”2回合。闪电链和地震术造成伤害时，100%触发被动升腾。

这应该是元素萨整套技能的最高规格演出。

它不是普通火球术，而是：

> **角色短暂化身为元素升腾者，融合雷霆、火焰和大地力量。**

## 第一阶段：元素静止

约0.2秒。

点击升腾后：

- 三颗技能点化为三道不同颜色的光芒；
- 青蓝代表雷电；
- 土金代表大地；
- 橙红代表火焰；
- 三道光流飞入元素萨角色。

同时：

- 战场亮度降低约20%；
- 所有角色暂时停止待机动作；
- 环境音被压低；
- 中央地面阵法开始旋转。

## 第二阶段：升腾变身

约0.35秒。

元素萨角色：

- 身体微微悬浮；
- 原角色卡牌保持在原位，但立绘变暗；
- 中央战场出现一尊半透明元素萨灵体；
- 灵体外形由火焰躯干、雷电双臂和岩石护甲构成；
- 头部与双眼发出炽白光芒；
- 背后出现巨大的元素圆环。

变身完成时，画面中央短暂出现：

```
升腾
```

文字使用橙金色毛笔字体，随后化为火星。

## 第三阶段：火球凝聚

约0.25秒。

升腾灵体张开双臂：

- 左手凝聚青蓝色雷电；
- 右手凝聚橙红色火焰；
- 雷电快速缠绕火球；
- 五颗大型熔火火球在角色身后形成扇形阵列；
- 地面裂缝中喷出小型火焰。

这里的火球必须比“根深蒂固”的被动火球更大、更亮。

### 被动火球

- 小；
- 快；
- 主要是橙色；
- 无全屏演出。

### 主动升腾火球

- 大；
- 带雷电；
- 炽白核心；
- 有明显蓄力和镜头效果。

## 第四阶段：全体轰击

约0.35秒。

五颗火球同时升空，然后从不同角度砸向敌方五人：

- 每颗火球带有长长的熔火尾迹；
- 火球飞过时照亮地面；
- 命中瞬间，先出现白色闪光；
- 随后发生橙红爆炸；
- 外围产生一圈青蓝雷电冲击环；
- 地面留下短暂的熔岩裂纹。

每名敌人飘出：

```
-16
```

数字为橙金色，外围带蓝白电弧。

## 第五阶段：获得升腾过载

火球轰击结束后：

- 元素灵体不会立即完全消失；
- 它缩小为一道元素轮廓，附着到元素萨角色身后；
- 角色卡牌边框变为蓝橙双色流光；
- 状态栏新增图标：

```
升腾过载  2
```

图标可以设计成：

- 左半边青蓝雷电；
- 右半边橙红火焰；
- 中央是一只发光的元素之眼；
- 外圈有两个金色节点，代表剩余两回合。

每经过一个回合：

```
2 → 1 → 消失
```

对应熄灭一个节点。

## 总时长

约：

**1.4～1.7秒**

作为大招，这个时长足够有仪式感，但不会拖慢回合制节奏。

# 六、升腾过载期间的技能变化

升腾过载期间，闪电链和地震术按钮也应该发生变化。

## 按钮变化

### 闪电链

原本青蓝色图标外围增加橙红火环。

鼠标悬停提示：

```
升腾过载
该技能必定触发根深蒂固
```

### 地震术

原本土黄色图标裂纹中流动橙红熔岩。

鼠标悬停提示：

```
升腾过载
该技能必定触发根深蒂固
```

## 闪电链过载演出

```
闪电链跳跃
→ 最后一道电流回收
→ 升腾印记亮起
→ 五颗火球追击
→ 回复1技能点
```

整体呈现：

> 蓝色雷电先手，橙色火焰追击。

## 地震术过载演出

```
第一次震击
→ 第二次震击
→ 第三次大地爆发
→ 地面裂缝变为熔红
→ 五颗火球从裂缝中飞出
→ 命中全体敌人
```

整体呈现：

> 大地先裂开，升腾火焰从地下喷发。

# 七、机制上需要提前明确的一处歧义

你当前文本写的是：

> “闪电链和地震术造成伤害时，100%触发被动升腾。”

这里有两种理解。

## 方案A：每次释放技能触发一次

闪电链：

- 触发1轮火球。

地震术：

- 三段伤害全部结束后，触发1轮火球。

这是我更推荐的方案。

优点：

- 演出清晰；
- 不会拖慢节奏；
- 数值容易控制；
- 不会出现大量重复火球遮挡画面。

## 方案B：每一段伤害都触发一次

地震术有三次伤害，那么会触发三轮火球：

```
地震7
→ 火球12

地震7
→ 火球12

地震7
→ 火球12
```

这相当于每名敌人受到：

```
21点地震伤害
+
36点火球伤害
=
57点伤害
```

再加上它自身只消耗2点，强度会非常高，而且一场动画会变得很长。

因此建议技能说明修改为：

> **升腾过载：持续2回合。期间每次释放闪电链或地震术后，必定触发一次根深蒂固。**

这样机制和演出都更清楚。

第一步先完成 **闪电链**，验证：

- 全体目标锚点；
- 雷电跳跃；
- 群体伤害数字；
- 技能点回复。

第二步完成 **地震术**，验证：

- 地面遮罩；
- 三段伤害；
- 镜头震动；
- 多目标多段数字。

第三步接入 **根深蒂固**，验证：

- 技能结束后的被动判定；
- 火球追击；

最后完成 **升腾**，验证：

- 变身；
- 大招火球；
- 两回合状态；
- 过载期间的100%触发。
