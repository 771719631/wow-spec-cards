# 一、推荐技术方案

## React/HTML UI + PixiJS 特效画布

界面分成两套系统：

```
HTML / React
├── 回合标题
├── 行动顺序
├── 血条和状态
├── 技能按钮
├── 角色信息
└── 提示面板

PixiJS Canvas
├── 战场角色
├── 刀光和子弹
├── 粒子
├── 残影
├── 伤害数字
├── 屏幕闪光
└── 全屏大招效果
```

PixiJS 可以直接对场景对象使用模糊、颜色矩阵、位移、噪声等滤镜，并支持 `add`、`screen`、`multiply` 等混合模式，很适合做刀光、火花、毒雾和发光纹章。[PixiJS](https://pixijs.com/8.x/guides/components/filters)

动画时序用 GSAP Timeline 管理，例如：

```
技能按钮按下
→ 角色蓄力
→ 冲向目标
→ 刀光出现
→ 命中
→ 飘伤害数字
→ 返回原位
```

GSAP Timeline 适合把多个动画串成完整技能流程，还可以统一控制动画倍速；你右上角的 `×2` 按钮就能关联整套战斗时间轴。[GSAP](https://gsap.com/docs/v3/GSAP/gsap.globalTimeline/)

如果你的项目已经使用 Phaser，也可以全部放在 Phaser 中实现，它原生提供镜头震动、闪光、缩放等效果。[Phaser 文档](https://docs.phaser.io/api-documentation/3.88.2/api-documentation)

对于你这个静态回合制战场，**React + PixiJS + GSAP** 比完整 Phaser 更轻、更容易和现有 HTML UI 融合。

# 二、画面图层怎么分

基于你刚才生成的庭院背景，战斗场景建议分为：

```
Layer 0：背景图
Layer 1：后景环境粒子
Layer 2：角色脚底阵法和阴影
Layer 3：敌我角色
Layer 4：角色后方特效
Layer 5：前景攻击特效
Layer 6：伤害数字与状态文字
Layer 7：HTML UI
Layer 8：全屏闪光、暗角、镜头特效
```

特别注意：

- 刀光要在角色前面。
- 角色脚底阵法要在角色后面。
- 雾气分前后两层，才会有空间感。
- UI 永远不参与镜头震动。
- 震动的只是中央战场画布，不是整个网页。

你的背景已经有一个巨大的圆形地面纹章，可以把它设置为：

> **所有技能表演的中央舞台**

敌方角色放在圆形阵法上半区，我方角色放在下半区，技能轨迹尽量经过中央区域。

# 三、统一的技能特效语言

现在选择的是潜行者·狂徒，所以特效不要全做成传统仙术。

建议用以下组合：

|内容|颜色与表现|
|---|---|
|物理刀光|银白色、略带冷灰|
|潜行与残影|黑色墨雾、深灰残影|
|毒药|祖母绿、黄绿色液滴|
|枪械|金橙色枪火、白色弹道|
|暴击|朱红墨爆、金色破裂纹|
|技能点|暖金色勾玉/灵珠|
|大招|红金、琥珀色、暗红烟雾|

因为背景已经以暗蓝色为主，技能不宜继续大量使用蓝色，否则会与背景融在一起。

最合适的是：

> **银白刀光 + 绿色毒素 + 金红暴击**

# 四、技能释放的统一流程

每一个技能都分成六个阶段：

```
1. 选择目标
2. 技能蓄势
3. 角色动作
4. 飞行或位移
5. 命中反馈
6. 状态结算
```

例如点击技能以后：

### 1. 选择目标

- 敌方角色周围出现朱红色毛笔圆框。
- 鼠标悬停目标时，脚下出现淡红阵法。
- 从当前角色到目标出现一条很淡的墨迹引导线。

### 2. 消耗技能点

你现在有 `3/8` 技能点。

使用一点技能时：

- 一颗金色灵珠从技能点栏飞向技能按钮。
- 灵珠进入按钮后破碎。
- 数字从 `3/8` 变为 `2/8`。

这一小段大约只需要 0.15 秒。

### 3. 当前角色突出

- 其他角色亮度降低约 20%。
- 当前角色向上浮起 8～12px。
- 金色边框快速亮一次。
- 角色脚下阵法旋转一圈。

### 4. 命中反馈

命中必须同时包含：

- 目标位移或抖动。
- 打击火花。
- 伤害数字。
- 短暂定格。
- 音效。
- 轻微镜头震动。

只出现伤害数字，没有角色反馈，会显得像网页计算器。

# 五、五个技能的具体设计

## 1. 普攻

### 表现目标

快速、清楚，不抢大招风头。

### 动画流程

```
角色卡牌前倾
→ 一道银白短刀光掠过目标
→ 目标轻微后仰
→ 小型火星飞散
→ 飘出普通伤害数字
```

### 时间

约 0.35～0.45 秒。

### 细节

- 刀光宽度较窄。
- 不使用全屏暗化。
- 目标左右抖动 4～6px。
- 伤害数字为米白色。
- 若带毒，则伤害后补一个绿色小数字。

---

## 2. 军刀猛刺

这是最适合展示“潜行者速度感”的技能。

### 蓄势

- 当前角色身体下沉。
- 角色周围出现黑色墨雾。
- 银色军刀边缘逐渐亮起绿色毒光。
- 脚下阵法快速收缩。

### 位移

角色瞬间冲向目标：

```
起点角色
→ 两道半透明残影
→ 黑灰色速度拖尾
→ 绿色细长刀光
→ 穿过目标
```

不要直接把卡牌拖过去。

更好的方式是：

- 原卡牌留在原位并变暗。
- 中央战场生成一个半透明角色剪影。
- 剪影冲刺经过目标。
- 完成后原卡重新亮起。

这样不需要制作完整角色动作素材。

### 命中

- 一道由左下到右上的细长银白斩痕。
- 斩痕中心带绿色毒液。
- 目标身上短暂保留一条绿色裂口。
- 绿色毒滴向外飞散。
- 目标后方爆出一小团黑色墨雾。

### 时间

约 0.6～0.75 秒。

### 镜头反馈

- 冲刺开始时镜头轻微拉近。
- 命中时暂停 60～80ms。
- 轻度镜头震动。

---

## 3. 手枪射击

这一招应强调“快枪手”，不要做成法术光球。

### 动画流程

```
角色边框金光一闪
→ 手枪剪影从角色侧面伸出
→ 橙金色枪口火焰
→ 一条极细的白金弹道
→ 目标处出现圆形冲击火花
→ 一枚弹壳旋转落下
```

### 枪口火焰

分三层：

1. 中心：纯白。
2. 中层：亮黄色。
3. 外层：橙红色烟火。

### 弹道

不要做成长时间持续激光。

应该是：

- 只存在 2～3 帧。
- 中间白色。
- 外围淡金色。
- 尾部有轻微空气扭曲。

### 时间

约 0.45～0.6 秒。

### 命中反馈

- 目标头像瞬间闪白。
- 目标后方出现放射状火星。
- 飘出橙黄色伤害数字。
- 枪声音效之后补一个短促金属回响。

---

## 4. 正中眉心

这是一个强力暴击技能，必须和普通枪击明显区分。

### 第一阶段：锁定

整个战场亮度降低约 25%。

目标身上出现：

- 朱红色毛笔圆环。
- 中心金色准星。
- 四周缓慢收紧的符纸边框。
- 目标名称短暂变为红色。

画面中央出现：

```
锁定
```

或者更有风格地使用一个红色印章动画。

### 第二阶段：压迫感

- 镜头向目标轻微放大到 105%。
- 环境声音暂时降低。
- 听到一次心跳。
- 准星完全闭合后暂停约 0.1 秒。

### 第三阶段：射击

枪响瞬间：

- 全屏白闪 1 帧。
- 金色子弹轨迹贯穿中央区域。
- 目标头部位置爆出红金色环形冲击波。
- 背景出现放射状墨裂纹。
- 目标大幅后仰。

### 第四阶段：暴击结果

显示：

```
暴击
-248
```

“暴击”使用朱红毛笔字体，伤害数字使用金色。

### 时间

约 0.9～1.1 秒。

### 镜头震动

- 先轻微向后推。
- 再快速回弹。
- 不要连续抖动，否则会显得廉价。

---

## 5. 命运骨骰

这是大招，重点不在“爆炸”，而在**仪式感和随机结果揭晓**。

### 第一阶段：战场静止

- 背景降低饱和度。
- 其他角色暂停动作。
- 中央地面阵法亮起暗红与金色纹路。
- 潜行者角色边缘出现金色轮廓。

### 第二阶段：骰子出现

五枚或六枚骨骰从暗红烟雾中出现：

```
骰子1：从左下飞入
骰子2：从右下飞入
骰子3：从上方落下
骰子4：环绕角色旋转
骰子5：镜头前景掠过
```

骰子不要整齐排列，要有大小远近变化。

### 第三阶段：投掷

- 骰子围绕中央角色旋转。
- 带出金色轨迹和红色烟雾。
- 最后一刻全部飞向画面中央。
- 碰撞后发出金色冲击波。
- 骰子落在地面阵法上。

### 第四阶段：揭晓结果

骰子依次亮起。

每一个结果对应一个增益，例如：

|骰子结果|视觉表现|
|---|---|
|攻击强化|红色刀刃印记|
|速度强化|青白风纹|
|暴击强化|金色准星|
|额外行动|紫色时钟符号|
|技能点恢复|金色灵珠|
|吸血|暗红血月符号|

抽到的增益图标从骰子飞向角色头像，附着在血条下方。

如果出现多个强力增益：

- 中央爆发金光。
- 出现“鸿运当头”之类的战斗提示。
- 音乐增加一层高昂的铜管或鼓点。

### 时间

建议 1.4～1.8 秒。

超过两秒会影响回合制战斗节奏，尤其是玩家开启二倍速以后。

# 六、角色卡牌怎么配合特效

你目前没有完整的角色动画，可以给卡牌本身做以下动画：

## 待机

- 上下浮动 1～2px。
- 边框非常微弱地呼吸。
- 角色立绘有轻微景深移动。

## 轮到行动

- 卡牌升高 10px。
- 金色边框发光。
- 角色脚下出现旋转圆环。
- 左侧行动条头像同步发光。

## 受到攻击

根据伤害类型：

- 普通伤害：左右快速抖动。
- 重击：向后倾斜并下沉。
- 暴击：卡牌短暂变红，出现裂纹。
- 中毒：绿色雾气环绕卡牌底部。
- 死亡：颜色褪去，像纸张一样破碎消散。

# 七、全局战斗反馈

## 伤害数字层级

|类型|颜色|大小|
|---|---|---|
|普通伤害|米白|100%|
|物理暴击|金黄|150%|
|毒药伤害|绿色|85%|
|治疗|青绿色|100%|
|护盾|淡金色|90%|
|未命中|灰白|90%|

数字出现时：

```
缩放 60% → 120% → 100%
向上漂浮
轻微左右随机偏移
0.7秒后消失
```

## 击中特效

每次命中至少需要三层：

```
中心亮点
+ 放射火花
+ 外围冲击环
```

只有一张刀光 PNG 会显得非常平。

## 镜头震动级别

|攻击等级|震动幅度|
|---|---|
|普通攻击|0～3px|
|一般技能|4～8px|
|重击/暴击|8～14px|
|大招|最多约18px|

UI 面板不要一起震动。

# 九、技能配置数据化

不要把每个技能的全部动画写死在组件里。

可以定义：

```
interface SkillVfxConfig {
  id: string;
  duration: number;
  targetType: "enemy" | "ally" | "self";
  color: string;
  camera: {
    zoom?: number;
    shake?: number;
    flash?: boolean;
  };
  stages: {
    name: "anticipation" | "travel" | "impact" | "resolve";
    duration: number;
    effect: string;
  }[];
}
```

例如“正中眉心”：

```
const betweenTheEyesVfx: SkillVfxConfig = {
  id: "between-the-eyes",
  duration: 1000,
  targetType: "enemy",
  color: "#c93732",
  camera: {
    zoom: 1.05,
    shake: 12,
    flash: true
  },
  stages: [
    {
      name: "anticipation",
      duration: 280,
      effect: "target-lock"
    },
    {
      name: "travel",
      duration: 100,
      effect: "golden-bullet"
    },
    {
      name: "impact",
      duration: 220,
      effect: "critical-headshot"
    },
    {
      name: "resolve",
      duration: 400,
      effect: "critical-damage-number"
    }
  ]
};
```

战斗数值和动画要分开：

```
技能逻辑决定：
造成多少伤害

动画系统决定：
什么时候显示伤害
什么时候震屏
什么时候播放音效
```

当 Timeline 到达 `impact` 节点时，再触发伤害数字和血条变化，视觉与数值就不会错位。

# 十、第一版实施顺序

不要一次性制作所有职业技能。

先做潜行者这五招，按下面顺序：

1. 建立中央 PixiJS 特效画布。
2. 建立角色坐标锚点系统。
3. 完成通用刀光、子弹、火花、伤害数字。
4. 实现“军刀猛刺”。
5. 实现“正中眉心”。
6. 实现“命运骨骰”。
7. 接入技能点消耗、血条变化和状态图标。
8. 接入暂停与二倍速。
9. 最后再加音效和环境粒子。

最先验证的两招应该是：

> **军刀猛刺 + 正中眉心**

前者验证位移、残影和近战打击；后者验证锁定、镜头、子弹和暴击反馈。只要这两招做好，后面绝大多数技能都可以复用同一套特效框架。
