# 一、毁灭术统一视觉语言

|系统|视觉表现|
|---|---|
|普通火焰|暗橙色火焰、炽白火芯、黑色浓烟|
|混乱魔法|邪能绿色核心、紫黑色边缘、空间扭曲|
|浩劫标记|暗红恶魔之眼、黑焰符文、红黑锁链|
|资源回复|燃烧的灵魂余烬飞回技能点栏|
|烧尽增幅|混乱之箭按钮周围点亮两枚余烬符印|
|暴击与爆发|红金色墨爆、空间裂缝、焦黑碎片|
|持续灼烧|目标卡牌下方出现火星、烟气和焦痕|

毁灭术的火焰不应太干净。建议每次爆炸都混合：

```
炽白火芯
+ 橙红火焰
+ 深红余焰
+ 黑色硫磺烟雾
+ 少量绿色混乱火花
```

这样不会像普通法师或元素萨。

# 二、烧尽

技能效果：

> 造成12点伤害，回复1点技能点。使下一个混乱之箭伤害提高20%，最多叠加2次。

烧尽是资源构筑技能，应该快速、利落，不能做得比混乱之箭更夸张。

## 动画流程

### 1. 火焰聚集，约0.12秒

毁灭术士角色卡牌向前浮起少许：

- 双手之间出现一团暗橙色火焰。
- 火焰外围缠绕少量绿色符文。
- 脚下浮现一个不完整的燃烧圆环。
- 身边有两三颗余烬向上飘起。

技能按钮快速亮起一圈橙色呼吸光。

### 2. 发射烧尽，约0.18秒

火焰凝聚成一枚扭曲的火焰弹，向目标飞去。

飞行表现：

- 不是圆形火球，而是细长、带尖锐头部的火焰流。
- 中央为炽白色。
- 外层为橙红火焰。
- 尾部拖出黑色烟痕和火星。
- 飞行路径略微弯曲，体现不稳定的恶魔火焰。

### 3. 命中目标，约0.15秒

命中后：

- 目标胸前出现小型橙红爆炸。
- 中央出现十字形火焰裂口。
- 黑烟向上翻卷。
- 卡牌快速向后倾斜。
- 飘出伤害数字：

```
-12
```

普通伤害数字为米白色，外围带暗橙描边。

### 4. 回复技能点，约0.16秒

从爆炸烟雾中飞出一枚燃烧的灵魂余烬：

```
目标位置
→ 橙金色余烬
→ 飞向技能点区域
→ 点亮一颗技能点
```

例如：

```
3/8 → 4/8
```

余烬进入资源槽时播放清脆但略带火焰燃烧感的提示音。

### 5. 增强混乱之箭

命中后，再从目标身上分离一颗更小的暗红余烬，飞向“混乱之箭”技能按钮。

第一次烧尽：

```
混乱之箭增幅：1层
伤害 +20%
```

按钮外围点亮第一枚余烬符印。

第二次烧尽：

```
混乱之箭增幅：2层
伤害 +40%
```

点亮第二枚符印，同时混乱之箭图标内部的绿色能量明显增强。

达到两层以后，再释放烧尽：

- 仍然造成伤害并回复技能点。
- 混乱之箭增幅不再增加。
- 两枚余烬只短暂闪烁，提示已经达到上限。

## 总时长

约 **0.55～0.65秒**。

# 三、混乱之箭

技能效果：

> 消耗2点技能点，造成50点伤害。烧尽叠加的增伤在命中时结算并清空。

这是毁灭术的核心单体爆发，必须有明显的压迫感，但不应长到打断战斗节奏。

## 伤害表现

|烧尽增幅|最终伤害|
|---|---|
|0层|50|
|1层，+20%|60|
|2层，+40%|70|

## 动画流程

### 1. 消耗技能点，约0.12秒

两颗技能点飞向混乱之箭按钮：

- 技能点在空中化为绿色与紫色能量。
- 能量被按钮中心吸收。
- 资源从 `3/8` 变为 `1/8`。

### 2. 战场压暗，约0.16秒

- 中央战场亮度降低约20%。
- 环境饱和度稍微下降。
- 其他角色的待机动画短暂停顿。
- 术士脚下出现紫黑色恶魔法阵。
- 两侧升起黑色硫磺烟雾。

术士双手之间生成一个缓慢旋转的邪能核心。

### 3. 增幅余烬融入

烧尽增幅层数通过实际动画进入混乱之箭：

第一层：

- 一枚暗红余烬绕着邪能核心旋转。
- 弹体体积增加约10%。

第二层：

- 第二枚余烬从另一侧进入。
- 混乱之箭外围出现金红色裂纹。
- 屏幕边缘出现轻微热浪扭曲。

同时可以短暂显示：

```
烧尽增幅 ×2
伤害 +40%
```

不要使用大弹窗，只在角色或技能按钮附近显示。

### 4. 混乱之箭成型，约0.20秒

混乱之箭外形建议设计成：

> 一颗带恶魔头骨轮廓的绿色混乱能量弹。

结构：

- 中心是炽白绿色火芯。
- 外层是绿色邪能火焰。
- 边缘缠绕紫黑色电弧。
- 后方拖出黑色烟雾和空间碎片。
- 箭头位置偶尔浮现模糊的恶魔面孔。

### 5. 飞行，约0.20秒

发射瞬间：

- 术士角色卡牌向后产生轻微反作用力。
- 混乱之箭带着低沉轰鸣飞向目标。
- 经过地面时照亮沿途石板。
- 周围空气发生折射。
- 弹体附近的小型落叶和尘埃被吸入尾迹。

镜头可以轻微跟随混乱之箭移动，但幅度不要过大。

### 6. 命中，约0.22秒

命中目标后分为三层：

第一层：

- 目标瞬间闪出纯白轮廓。

第二层：

- 绿色混乱能量从目标内部爆开。
- 形成一个短暂的恶魔头骨冲击波。

第三层：

- 外围爆出紫黑色烟雾、火星和焦黑碎片。
- 地面留下绿色与红色交错的裂纹。

目标卡牌：

- 快速后仰。
- 短暂停顿约70毫秒。
- 出现轻微裂纹。
- 随后恢复位置。

显示大型伤害数字：

```
-50
```

有一层增幅：

```
-60
烧尽增幅
```

有两层增幅：

```
-70
完全增幅
```

数字使用绿色核心、金红色外描边。

### 7. 清空烧尽增幅

根据你的说明，增幅在**命中时**结算并清空。

因此混乱之箭命中的一瞬间：

- 两枚余烬符印依次碎裂。
- 碎片被爆炸吸入。
- 混乱之箭按钮恢复普通状态。

若游戏未来有未命中或闪避机制，建议遵守文字描述：**未命中时不清空增幅**。

## 镜头反馈

- 发射时轻微拉近至103%。
- 命中时进行70毫秒定格。
- 镜头震动约10～12px。
- 屏幕快速闪白一帧。
- HTML技能栏和回合UI不参与震动。

## 总时长

约 **0.9～1.1秒**。

# 四、浩劫

技能效果：

> 不消耗技能点。对一名敌人施加浩劫。此后烧尽和混乱之箭会同步攻击该目标。

浩劫不是伤害技能，而是战术标记。因此动画应该短，但标记必须非常清楚。

## 选择目标

点击浩劫后：

- 敌方可选角色脚下出现暗红色圆环。
- 当前悬停目标周围出现两只弯曲恶魔角。
- 其他角色亮度降低15%。
- 鼠标指针可以变为红黑色恶魔之眼。

## 施加过程

### 1. 恶魔符印出现，约0.15秒

目标脚下浮现一个暗红色恶魔法阵。

法阵中出现：

- 骷髅轮廓。
- 两根弯曲的恶魔角。
- 破碎的圆环符文。
- 向外扩散的黑色火焰。

### 2. 浩劫烙印，约0.20秒

一道暗红光束从术士射向目标。

命中后：

- 目标卡牌后方出现半透明恶魔之眼。
- 角色边框变为暗红色。
- 血条下方新增“浩劫”图标。
- 卡牌周围缓慢飘散黑红色灰烬。

目标头顶短暂显示：

```
浩劫
```

文字随后化成灰烬。

## 常驻状态表现

浩劫持续期间：

- 目标卡牌后方保留暗红恶魔之眼。
- 恶魔之眼偶尔睁开并闪光。
- 角色脚下有非常淡的黑焰。
- 状态图标显示剩余回合或剩余触发次数。

你当前技能说明没有写浩劫的持续时间，特效系统应将持续时间做成配置项：

```
havoc.durationTurns
```

不要写死在动画组件中。

## 烧尽触发浩劫

术士释放烧尽时：

```
主烧尽火焰 → 当前攻击目标
暗红影焰复制体 → 浩劫目标
```

复制方式：

- 主火焰发射后约60毫秒。
- 一道较暗的影焰从主投射物中分离。
- 影焰沿另一条弧线飞向浩劫目标。
- 浩劫目标背后的恶魔之眼在影焰命中前睁开。

浩劫复制的烧尽：

- 外层颜色由橙色改为暗红与黑色。
- 伤害数字旁边显示小型“浩劫”标记。
- 不应该额外回复技能点。
- 不应该额外增加混乱之箭增幅层数。

因为它是一次同步复制伤害，不是术士第二次释放烧尽。这样可以避免资源翻倍。

## 混乱之箭触发浩劫

混乱之箭飞行到约三分之一距离时：

- 主弹体发生一次空间震荡。
- 一枚红黑色混乱之箭复制体从侧面分裂出去。
- 主弹攻击当前目标。
- 复制体攻击浩劫目标。

浩劫复制体：

- 体积比主弹小约10%。
- 外围带暗红色裂纹。
- 保留绿色混乱核心。
- 命中稍晚约80毫秒，形成连续两次冲击。

复制体使用主混乱之箭结算后的最终伤害：

```
基础50
或增幅后的60/70
```

但：

- 只消耗一次技能点。
- 只清空一次烧尽增幅。
- 不重复计算资源和层数。

主攻击目标与浩劫目标是同一个单位时，不产生第二次复制攻击。

## 总时长

首次施加约 **0.4～0.5秒**。

触发复制时，仅在原技能动画后增加约 **0.1～0.2秒**。

# 五、火焰之雨

技能效果：

> 消耗4点技能点，对敌方全体造成4次10点火焰伤害。

这是毁灭术的大范围清场技能，重点是：

> **四次伤害必须有清楚的波次感，不能变成一团持续火焰看不懂结算。**

## 动画流程

### 1. 消耗资源，约0.15秒

四颗技能点飞向火焰之雨技能按钮：

- 每颗技能点变成一团火焰。
- 四团火焰依次进入技能图标。
- 图标外围形成完整的红金色火环。
- 技能点从 `4/8` 变为 `0/8`。

### 2. 战场预警，约0.25秒

敌方区域地面出现一座大型熔火法阵。

法阵包含四层同心圆，对应四次伤害：

```
第一圈
第二圈
第三圈
第四圈
```

视觉表现：

- 石板裂缝中出现暗红熔岩。
- 地面升起热浪。
- 火星向天空反向飘动。
- 敌方角色脚下出现燃烧警告环。
- 天空上方形成旋转的黑红火云。

### 3. 第一波：火星坠落

- 大量小型燃烧碎片落下。
- 每个敌人附近落下一至两颗。
- 爆炸规模较小。
- 每名敌人受到：

```
-10
第1/4段
```

镜头只轻微震动约3px。

### 4. 第二波：火球轰击

约0.18秒后：

- 较大的火球从斜上方砸落。
- 橙红爆炸覆盖敌方阵列。
- 地面熔岩裂纹进一步扩大。
- 每名敌人受到：

```
-10
第2/4段
```

镜头震动提升到5px。

### 5. 第三波：混乱流星

约0.18秒后：

- 绿色与橙红交织的混乱流星落下。
- 部分流星从前景掠过，制造纵深。
- 爆炸中加入紫黑色空间裂纹。
- 每名敌人受到：

```
-10
第3/4段
```

镜头震动约7px。

### 6. 第四波：毁灭陨落

最后一波必须明显强于前三波：

- 一颗大型陨石出现在敌方阵列上空。
- 陨石中心为炽白。
- 外围包裹橙红火焰和黑色烟雾。
- 表面有绿色恶魔符文。
- 陨石落地时产生一圈横向火焰冲击波。
- 地面熔岩裂纹全部亮起。
- 每名敌人受到：

```
-10
第4/4段
```

镜头震动约10～14px，并短暂停顿50毫秒。

## 伤害数字展示

五名敌人乘以四次伤害，会产生20个数字，很容易遮挡画面。

推荐每名敌人使用固定的伤害锚点：

```
第1次：-10   ×1
第2次：-10   ×2
第3次：-10   ×3
第4次：-10   ×4
```

每次只替换同一个数字，不要叠出四排。

技能结束后可以短暂显示：

```
总计 -40
```

但血条必须在四次命中时分别下降，保留多段攻击的真实结算。

## 技能结束

- 火云逐渐散去。
- 空中仍有灰烬缓慢落下。
- 地面焦痕保留约1秒。
- 熔岩裂纹逐渐冷却成黑色。
- 敌方角色边缘保留短暂灼烧烟雾。

浩劫只会同步烧尽和混乱之箭，因此火焰之雨不触发浩劫复制。

## 总时长

正常速度约 **1.25～1.5秒**。

二倍速约 **0.7～0.85秒**。

# 六、毁灭术的技能状态面板

为了让玩家看懂烧尽、混乱之箭和浩劫之间的关系，建议在毁灭术角色信息区增加两个非常重要的状态。

## 烧尽增幅

放在混乱之箭按钮附近：

```
烧尽增幅
◇ ◇
```

没有层数：

```
◇ ◇
```

一层：

```
◆ ◇   +20%
```

两层：

```
◆ ◆   +40%
```

第一层为暗橙色，第二层点亮后变成红金色，并出现轻微火焰呼吸动画。

## 浩劫目标

角色信息面板显示：

```
浩劫目标：死亡骑士·鲜血
```

旁边放置敌方头像和剩余时间。

同时在浩劫技能图标周围显示一条暗红色持续状态环。

# 七、技能联动演出

## 烧尽 → 混乱之箭

```
烧尽命中
→ 回复1技能点
→ 增幅混乱之箭
→ 再次烧尽
→ 达到2层
→ 混乱之箭体积和亮度提升
→ 命中造成70点伤害
→ 增幅清空
```

这是毁灭术最重要的视觉成长闭环。

## 浩劫 → 烧尽

```
烧尽攻击主目标
→ 影焰分裂
→ 同步攻击浩劫目标
→ 只回复一次技能点
→ 只增加一次烧尽增幅
```

## 浩劫 → 混乱之箭

```
混乱之箭发射
→ 中途分裂出红黑复制体
→ 主目标先爆炸
→ 浩劫目标延迟80毫秒爆炸
→ 使用相同最终伤害
→ 只清空一次增幅
```

## 火焰之雨

独立的全体四段攻击：

- 不触发浩劫。
- 不增加烧尽增幅。
- 不回复技能点。
- 不消耗混乱之箭增幅。

# 八、四个技能的视觉层级

|技能|视觉强度|建议时长|核心识别点|
|---|---|---|---|
|烧尽|中低|0.6秒|暗橙火焰、余烬回复、混乱箭叠层|
|混乱之箭|高|1秒|绿紫混乱弹、空间扭曲、单体重击|
|浩劫|中低|0.45秒|暗红恶魔之眼、影焰复制|
|火焰之雨|最高|1.4秒|四波陨火、焦土地面、群体多段伤害|

火焰之雨的场面最大，混乱之箭的单次打击感最强。

# 十一、建议实现顺序

第一步先实现：

> **烧尽 → 回复技能点 → 点亮混乱之箭增幅。**

第二步实现：

> **混乱之箭读取增幅层数 → 计算50/60/70伤害 → 命中时清空。**

这两个技能完成后，毁灭术的核心循环就成立了。

第三步加入浩劫：

- 标记目标。
- 复制投射物。
- 复制最终伤害。
- 禁止额外回复资源和增加层数。

最后实现火焰之雨：

- 四段伤害。
- 四种递进波次。
- 多目标固定数字锚点。
- 最后一段强震屏。

其中最需要优先做好的不是火焰规模，而是**烧尽增幅在混乱之箭按钮上的清晰反馈**。玩家只要能一眼看出“现在是一层还是两层、下一发混乱之箭能打多少”，毁灭术的操作爽点就真正建立起来了。
