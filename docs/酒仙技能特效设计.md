酿酒武僧形成自己的视觉语言：

> **青玉酒气 + 琥珀酒液 + 水墨笔触 + 玄牛图腾**

这样能和潜行者的“银白刀光、绿色毒雾、红金暴击”明显区分。

# 一、酿酒武僧统一特效语言

## 主色与材质

- **青玉绿**：护盾、治愈、能量回复。
- **琥珀金**：酒液、醉意、技能点。
- **墨黑色**：玄牛、承伤、厚重防御。
- **古铜金**：技能边框、符文、命中特效。
- **乳白雾气**：酒气和天神能量。

## 通用动作反馈

武僧释放技能时，不一定需要完整人物骨骼动画，可以采用：

```
角色立绘前倾或抬手
→ 酒葫芦、酒坛、玄牛剪影出现
→ 中央战场播放特效
→ 数值与状态结算
→ 角色恢复待机
```

角色待机时可以有很轻微的：

- 身体左右摇晃。
- 酒葫芦随呼吸晃动。
- 脚下青绿色酒气慢慢扩散。
- 偶尔出现一两个琥珀色气泡。

# 二、醉酿投

技能效果：

> 造成10点伤害，回复1点技能点。

## 核心表现

不是普通“扔一个绿色罐子”，而是一只装满灵酒的小酒坛划出弧线砸向敌人。

## 完整动画流程

### 1. 起手，约0.12秒

当前武僧角色：

- 身体微微后仰。
- 右手出现一个小型青绿色酒坛。
- 酒坛表面浮现发光的武僧印记。
- 角色脚下产生一圈琥珀色酒液波纹。

技能按钮中的酒坛图标短暂放大并发光。

### 2. 投掷，约0.20秒

酒坛从我方角色位置飞向目标：

- 走一条明显的抛物线。
- 飞行时快速旋转。
- 后方拖出青玉绿与琥珀金交织的液体尾迹。
- 尾迹中带少量透明酒滴。

不要做成魔法光球，要保留酒坛的实体重量感。

### 3. 命中，约0.18秒

酒坛击中敌方角色后：

- 陶坛瞬间碎裂。
- 琥珀色酒液向四周炸开。
- 外围出现一圈青绿色冲击波。
- 几片木屑或陶片向外飞散。
- 敌人角色短促后仰并抖动。

伤害数字：

```
-10
```

使用米白数字，外围带琥珀色描边。

### 4. 回复技能点，约0.20秒

命中后，从破碎酒液中凝聚出一颗小型金色酒珠：

```
敌人位置
→ 金色酒珠
→ 飞回技能点区域
→ 点亮一颗技能点
```

技能点数字例如从：

```
3/8 → 4/8
```

金色酒珠进入技能点时，播放一声清脆的玉石碰撞声。

## 音效

- 起手：酒坛轻晃与液体声。
- 飞行：短促风声。
- 命中：陶罐碎裂、液体泼洒。
- 回复：清脆玉石提示音。

## 动画时长

正常速度约 **0.65秒**，二倍速约 **0.35秒**。

# 三、天神灌注

技能效果：

> 为一名友方增加32点护盾，并使其伤害提高30%，持续2回合。

这是一个“护盾＋攻击增益”的复合技能，所以特效必须让玩家明确看出两个结果。

## 核心表现

武僧举起酒葫芦，将蕴含天神力量的青玉灵酒灌入友方体内，随后形成护盾和攻击符印。

## 完整动画流程

### 1. 选择目标

可选择的友方角色：

- 脚下出现青玉绿色莲花阵。
- 角色边框产生柔和金光。
- 不可选角色亮度降低。

从技能按钮到友方目标之间出现一条淡淡的青绿色酒气引导线。

### 2. 引导，约0.25秒

武僧头顶浮现一只半透明酒葫芦。

葫芦缓慢倾斜：

- 青绿色灵酒化为一条光流。
- 光流中夹杂金色小颗粒。
- 光流绕过中央战场，注入友方角色。

背景音效暂时减弱，突出液体流动和铃声。

### 3. 护盾生成，约0.25秒

友方角色周围依次形成三层护盾：

1. 内层：薄薄的青绿色透明圆罩。
2. 中层：金色六边形或古代窗棂纹样。
3. 外层：短暂浮现一只玄牛角形轮廓。

护盾值在角色血条上方显示：

```
护盾 +32
```

血条外增加一条青玉色护盾条。

### 4. 伤害提高，约0.20秒

护盾形成后：

- 一个朱红与金色组合的攻击符印出现在目标头顶。
- 符印形状可以是双拳、刀锋或向上的箭头。
- 符印化作流光进入角色胸口。
- 角色立绘边缘短暂闪现金红色轮廓。

显示：

```
伤害提高 30%
```

### 5. 持续回合提示

角色状态栏新增两个图标：

```
青玉护盾图标  2
金色攻击图标  2
```

每经过一回合，数字：

```
2 → 1 → 消失
```

最后一回合结束时，护盾像薄玉一样碎裂成光点。

## 音效

- 酒液流动声。
- 清脆玉铃。
- 护盾生成时的低沉铜钟。
- 增伤生效时短促的金属拔刀声。

## 动画时长

约 **0.85～1秒**。

# 四、醉拳

技能效果：

> 被动：受到伤害时只承受50%，其余伤害在后续3回合内平均偿还。

这个技能最重要的不是做一个漂亮动画，而是让玩家一眼理解：

> 哪部分伤害已经受到，哪部分伤害被延后了。

## 推荐增加“醉拳延迟伤害条”

在武僧血条下方增加一条较细的琥珀色状态条：

```
生命值    ███████
醉拳值    ███
```

或者显示：

```
待偿还伤害：18
剩余3回合
```

## 首次受到攻击

假设敌人造成30点伤害。

### 1. 命中反馈

敌方技能击中武僧。

武僧并不直接僵直，而是：

- 身体向一侧歪斜。
- 出现两道半透明醉影。
- 攻击轨迹像从角色身体旁边滑开。
- 脚下酒液波纹产生倾斜晃动。

视觉上表现“卸掉一半力量”。

### 2. 立即伤害

先飘出：

```
-15
```

数字为正常红色。

### 3. 延迟伤害

剩余15点不立即扣除。

这15点伤害化为三颗琥珀红色酒滴：

```
5    5    5
```

酒滴依次飞入武僧腰间的酒葫芦，或者进入血条下方的醉拳槽。

画面显示：

```
醉拳延迟：15
```

随后显示：

```
每回合承受5点，持续3回合
```

不要同时在画面上保留过多文字，可以先出现“延迟15”，然后在状态栏中通过数字表达。

## 后续回合结算

每个回合结束时：

- 酒葫芦轻轻震动。
- 一滴暗红色酒液从葫芦中溢出。
- 琥珀色醉拳槽减少三分之一。
- 武僧轻微摇晃。
- 飘出一次小型延迟伤害数字。

例如：

```
醉拳 -5
```

数字使用暗橙色，不要和普通伤害共用鲜红色。

## 醉拳堆积过高

如果后续允许醉拳伤害叠加，可以设计三个强度阶段：

|醉拳值|视觉状态|
|---|---|
|低|淡黄色酒气|
|中|橙色酒雾，角色轻微摇晃|
|高|暗红色酒气，酒葫芦剧烈震动|

高额醉拳值时，血条下方增加轻微警告闪烁。

## 重要机制说明

醉拳不是一个主动技能，因此：

- 不播放完整施法动画。
- 每次受到伤害只播放约0.25～0.4秒反馈。
- 延迟伤害结算控制在0.2秒左右。
- 不要让它明显打断战斗节奏。

# 五、玄牛下凡

技能效果：

> 召唤玄牛，为队友分担50%伤害，持续2回合。

## 机制上的一个关键约定

按你当前技能说明，玄牛没有单独生命值。因此首版建议把它做成：

> **持续2回合的守护状态，而不是可以被攻击的独立召唤单位。**

这样不会额外引入玄牛血量、死亡、控制和行动顺序等新规则。

## 核心表现

玄牛不是普通黑牛，而是一只由水墨、岩石和青玉光芒构成的巨大天神守护兽。

## 完整召唤流程

### 1. 开始召唤，约0.25秒

武僧角色双手合十或重拳砸地。

中央战场：

- 画面亮度降低约15%。
- 地面金色阵法转为黑金色。
- 一圈浓重墨汁从中央向外扩散。
- 地面出现巨大牛蹄印。

播放一声低沉铜鼓。

### 2. 玄牛出现，约0.45秒

墨迹和尘雾从地面升起：

```
巨大牛角轮廓
→ 头部
→ 肩背
→ 完整玄牛
```

玄牛外观：

- 主体为深黑与岩石灰。
- 牛角带青玉绿色纹路。
- 额头有金色武僧符文。
- 蹄下燃烧青绿色灵火。
- 身体边缘不断散出水墨粒子。

玄牛从阵法中踏出时：

- 地面轻微震动。
- 落叶和尘埃被震起。
- 两侧灯笼产生很轻的晃动。

### 3. 建立守护连接，约0.25秒

玄牛站在我方阵容后方或中央，不遮挡角色 UI。

它与每一名队友之间生成一条极淡的墨金色连接线。

每名队友脚下出现：

```
玄牛守护
```

状态图标是一只黑金色牛角。

显示持续时间：

```
2回合
```

## 为队友分担伤害的表现

假设队友受到20点伤害。

### 命中队友

- 敌方攻击照常击中队友。
- 队友只飘出：

```
-10
```

### 伤害转移

剩余10点伤害化为一团红黑色能量：

```
队友
→ 沿墨色连接线
→ 飞向玄牛
```

玄牛承接伤害时：

- 身体向后沉一下。
- 四蹄踏地。
- 额头符文亮起。
- 背后爆出一圈黑金色冲击波。

玄牛上方显示：

```
分担 10
```

不要使用普通生命伤害的红色数字，因为它不是独立单位扣血，而是技能机制反馈。

## 持续状态

玄牛留在战场后方：

- 缓慢呼吸。
- 蹄下墨雾流动。
- 偶尔抬头或甩尾。
- 不参与行动顺序。
- 不占角色位置。
- 不遮挡敌我角色。

第一回合结束：

- 一个金色牛角印记熄灭。
- 剩余持续时间变为1。

第二回合结束：

- 玄牛向前踏一步。
- 发出低沉吼声。
- 身体化为向上飘散的水墨和青玉光点。
- 最后只留下一个逐渐消失的牛蹄印。

## 音效

- 召唤：低沉牛吼、战鼓、岩石摩擦。
- 落地：厚重踩地声。
- 分担伤害：低频冲击、锁链绷紧或铜钟声。
- 消失：风声和墨汁散开的声音。

## 动画时长

首次召唤约 **1.1～1.3秒**。

之后每次分担伤害约 **0.3～0.4秒**。

# 六、四个技能的表现层级

|技能|视觉强度|推荐时长|核心辨识点|
|---|---|---|---|
|醉酿投|中低|0.65秒|酒坛飞行、碎裂、技能点飞回|
|天神灌注|中|0.9秒|青玉护盾、增伤符印|
|醉拳|低频持续|0.25～0.4秒|伤害一分为二、醉拳延迟槽|
|玄牛下凡|高|1.2秒|黑金玄牛、水墨召唤、伤害转移|

这样可以避免每一招都像大招。

# 七、技能点反馈

你这名武僧的技能会消耗和回复技能点，技能点最好改成和职业风格匹配的**琥珀酒珠**：

```
● ● ● ○ ○ ○ ○ ○
可用 3/8
```

使用技能：

- 酒珠飞向技能按钮。
- 酒珠碎成金色液滴。
- 技能点减少。

醉酿投回复：

- 酒珠从敌人位置飞回。
- 空槽重新被点亮。
- 播放清脆提示音。

这种表现比数字直接变化更有游戏感。

# 九、优先实施顺序

建议先做：

1. **醉酿投**：验证抛物线、命中和技能点回复。
2. **醉拳**：验证伤害拆分和持续结算。
3. **天神灌注**：验证护盾、增伤和回合计数。
4. **玄牛下凡**：最后完成召唤、驻场与伤害转移。

其中最重要的是**醉拳的信息表达**。只要玩家能清楚看到“立即伤害”和“后续待偿还伤害”，这名酿酒武僧的职业特色就真正立住了。
