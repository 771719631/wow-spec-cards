# 一、神圣牧师统一特效语言

## 色彩体系

|用途|主要颜色|视觉含义|
|---|---|---|
|神圣伤害|炽白、香槟金|集中、纯净、审判感|
|单体治疗|暖白、淡金、薄荷青|迅速恢复生命|
|能量灌注|白金、浅紫、淡蓝|加速、赋能、额外行动|
|群体治疗|象牙白、晨曦金、淡粉|恢宏、柔和、希望|
|技能点回复|金色祷文光珠|神圣能量回流|

神牧的特效形状以这些元素为主：

- 八芒日轮；
- 金色经文圆环；
- 柔和羽光；
- 细小星尘；
- 莲瓣或花瓣状光片；
- 半透明丝带光流；
- 钟磬式圆形声波。

不要给神牧大量使用：

- 烈焰爆炸；
- 厚重烟雾；
- 岩石碎片；
- 高强度镜头震动；
- 过多绿色治疗光。

治疗数字可以用薄荷青，但主体光效仍以白金色为主。

# 二、惩击

技能效果：

> 造成8点伤害，回复1点技能点。

惩击是神牧的基础攻击，表现应该**快速、干净、带审判感**，不能做成法师火球。

## 完整动画流程

### 1. 神圣凝聚，约0.12秒

牧师角色卡牌向上浮起约8px：

- 身后亮起一枚小型八芒日轮；
- 双手之间聚集一颗炽白光点；
- 数条金色经文沿圆环旋转；
- 角色周围产生少量向上飘动的光尘。

技能按钮快速亮起一圈暖金色边框。

### 2. 锁定敌人，约0.08秒

敌方目标脚下出现一个细小金色符印。

目标卡牌边缘短暂变成暖白色，提示神圣力量已经锁定目标。

### 3. 神圣光矛落下，约0.15秒

一道细长的白金色神圣光矛，从斜上方快速刺向目标：

```
牧师凝聚圣光
→ 白金光矛划过战场
→ 命中敌方目标
```

光矛结构分三层：

1. 中心为近乎纯白的高亮光芯；
2. 中层为香槟金；
3. 外围带少量淡黄色星尘。

它应该比普通子弹更亮，但比大招光柱更窄。

### 4. 命中反馈，约0.14秒

命中目标后：

- 目标胸前爆开一枚八芒日轮；
- 外围扩散一圈极薄的金色冲击环；
- 少量发光羽片向外飞散；
- 目标卡牌轻微后仰；
- 卡牌亮度瞬间提高，再迅速恢复。

显示伤害数字：

```
-8
```

数字使用象牙白，外围带淡金描边。

### 5. 回复技能点，约0.16秒

命中后，八芒日轮中心凝聚出一颗金色祷文光珠：

```
目标位置
→ 金色光珠
→ 飞向技能点区域
→ 点亮一颗技能点
```

例如：

```
3/8 → 4/8
```

技能点槽被点亮时，播放一声短促清脆的钟铃。

## 镜头反馈

- 不需要明显震屏；
- 命中时只做1～2px轻微冲击；
- 战场可以短暂提高曝光；
- UI面板保持固定。

## 总时长

正常速度约：

**0.55～0.65秒**

# 三、快速治疗

技能效果：

> 消耗1点技能点，为一名友方恢复26点生命。

快速治疗的重点是：

> **快速、明确、救急，不做过长的施法仪式。**

玩家点击以后，应当在半秒左右看到血条明显回升。

## 目标选择

点击技能后，可治疗的友方角色：

- 脚下出现淡金色莲瓣光环；
- 血量较低的角色光环更明显；
- 满血目标亮度稍低；
- 鼠标悬停时显示预计恢复量。

例如：

```
预计恢复：26
```

## 完整动画流程

### 1. 消耗技能点，约0.1秒

一颗技能点化为金色光珠，飞入快速治疗按钮。

资源例如：

```
3/8 → 2/8
```

### 2. 瞬间祈祷，约0.12秒

牧师双手之间产生一枚暖白色光团。

角色身后的日轮只亮起一半，表示这是快速施法，而非完整仪式。

光团内部有细小金色文字和星点。

### 3. 治疗光流，约0.16秒

光团化为一条柔软的白金色光带，迅速飞向目标。

光带不能像激光一样僵硬，应带有：

- 轻微弧线；
- 柔和拖尾；
- 羽光颗粒；
- 少量淡青色生命星点。

### 4. 治疗生效，约0.2秒

目标脚下的莲瓣光环向上展开：

```
脚底光环
→ 光线沿身体上升
→ 角色边缘被暖光包围
→ 血条回升
```

角色周围出现一圈透明暖白护光，但不形成护盾，避免与护盾技能混淆。

显示：

```
+26
```

治疗数字使用薄荷青，外围带白金色光晕。

血条不要瞬间跳变，建议在0.2～0.25秒内平滑上升。

### 5. 过量治疗反馈

如果目标缺少的生命少于26点，可以在治疗数字下方出现较小提示：

```
过量治疗 8
```

或者仅让多余的光点向上消散，不长期显示文字。

## 音效

- 轻柔吸气式神圣音效；
- 短促铃声；
- 治疗生效时加入柔和的水晶共鸣；
- 不使用厚重爆炸或长合唱。

## 总时长

约：

**0.55～0.7秒**

# 四、能量灌注

技能效果：

> 消耗2点技能点，使一名友方立即获得回合，并在本回合伤害提高20%。

这是神牧最有战术价值的技能。它的特效不能只显示“伤害提高20%”，还必须明确告诉玩家：

> **这名角色现在插入了行动顺序。**

因此特效需要同时影响：

- 战场角色；
- 左侧行动顺序；
- 当前回合标题；
- 增伤状态。

---

## 目标选择

点击技能以后：

- 所有可选友方脚下出现白金色日轮；
- 当前悬停角色周围浮现浅紫色加速纹；
- 目标头像旁显示：

```
立即行动
伤害 +20%
```

其他不可选角色亮度降低约15%。

---

## 完整动画流程

### 1. 消耗技能点，约0.14秒

两颗技能点分别化为：

- 一颗白金色光珠；
- 一颗浅紫色光珠。

两颗光珠螺旋进入能量灌注按钮。

例如：

```
3/8 → 1/8
```

### 2. 神圣冠冕降临，约0.2秒

目标角色上方出现一枚由白金色经文组成的圆形冠冕。

冠冕缓慢下降，并在目标头顶展开：

- 中心是八芒日轮；
- 外圈是浅紫色速度纹；
- 两侧展开半透明羽光；
- 目标角色边缘出现金色轮廓。

### 3. 能量注入，约0.2秒

数道白金与浅紫色光线，从冠冕注入目标：

- 角色卡牌向前突出；
- 立绘亮度提高；
- 角色身后出现两道快速残影；
- 脚下日轮加速旋转；
- 衣摆和头发产生被能量吹动的效果。

显示：

```
能量灌注
```

随后文字分解成光点。

---

## 立即获得回合的UI表现

这是该技能最关键的一步。

### 方案一：获得额外回合

如果你的规则是“额外插入一个回合”，行动条应该：

```
原行动顺序：
A → B → C → D

使用能量灌注后：
目标角色 → A → B → C → D
```

视觉表现：

- 从目标角色位置复制一个发光头像；
- 头像沿金色轨迹飞到行动条最前方；
- 原来的行动头像仍保留；
- 新头像外围带白金色“额外行动”标识。

这样玩家能看出，这是额外回合，不是单纯提前行动。

### 方案二：提前本轮行动

如果规则是“将原本回合提前”，则：

- 不复制头像；
- 直接把目标头像从原位置移动到行动条首位；
- 后续头像自动补位；
- 原来的行动位置消失。

这两种机制必须在程序中明确，不能只用同一种动画。

从技能强度来看，消耗2点后“立即获得回合”，我更建议采用：

> **插入额外行动，但该额外行动只能持续本回合增伤。**

---

## 增伤状态表现

目标获得行动后：

- 卡牌边框变成白金与浅紫双色流光；
- 武器、技能按钮或职业图标出现轻微金色闪烁；
- 状态栏新增图标：

```
能量灌注
伤害 +20%
本回合
```

图标设计：

- 中央为金色日轮；
- 外围是浅紫色箭头；
- 下方显示数字“1”，表示仅持续当前回合。

### 攻击时的强化反馈

目标在该回合造成伤害时：

- 攻击特效边缘附加一层淡金色回响；
- 命中后产生第二圈较薄的神圣冲击环；
- 伤害数字右上角显示：

```
+20%
```

不建议额外再弹一个独立伤害数字，以免玩家误以为造成了两次伤害。

### 回合结束

角色行动完成后：

- 头顶冠冕碎成金色光点；
- 边框恢复正常；
- 状态图标熄灭；
- 行动条上的额外头像化为羽光消散。

## 总时长

施法演出约：

**0.8～1秒**

行动条调整包含在其中。

# 五、神圣赞美诗

技能效果：

> 消耗3点技能点，为己方全体恢复24点生命。

这是神牧的最高规格技能。

它不能像普通群体治疗一样，同时弹出五条光线就结束。它应该具有：

- 仪式感；
- 全场安定感；
- 群体恢复的清晰反馈；
- 温暖而不刺眼的高潮。

默认按照：

> **每一名己方单位恢复24点生命**

来设计。

---

## 完整动画流程

### 1. 消耗技能点，约0.15秒

三颗技能点从资源栏升起，分别化为三枚金色音符光珠。

它们依次进入神圣赞美诗按钮：

```
技能点 ×3
→ 音符光珠
→ 技能图标
```

按钮外围出现完整的暖金色经文圆环。

### 2. 战场安静，约0.18秒

- 战场亮度降低约10%；
- 背景环境音减弱；
- 敌方角色颜色稍微变暗；
- 我方角色保持原有亮度；
- 中央地面阵法缓慢亮起象牙白与金色纹路。

不是黑屏，而是让战场进入柔和的神圣静默。

### 3. 牧师吟唱，约0.28秒

牧师身后展开一个大型日轮：

- 内圈为八芒星；
- 中圈为旋转经文；
- 外圈为柔和莲瓣；
- 周围漂浮金色音符和发光羽片。

牧师角色轻微悬浮。

角色上方出现几行抽象的发光经文，不要使用真实可读的大段文字，避免画面杂乱。

### 4. 圣光覆盖全队，约0.25秒

从牧师身后的日轮中伸出五条柔软光带，分别连接五名友方。

每一名友方脚下同时亮起小型莲瓣法阵。

随后五道暖白色光柱从上方落下：

```
友方1  友方2  友方3  友方4  友方5
  ↓      ↓      ↓      ↓      ↓
      神圣赞美诗覆盖全队
```

光柱不是完全垂直的硬光束，而是带有柔和雾化边缘。

### 5. 群体治疗结算，约0.25秒

中央日轮向外扩散一圈巨大的暖金色光波。

光波经过每名友方角色时：

- 血条平滑回升；
- 角色边缘被白金光包裹；
- 负面压迫感短暂消退；
- 飘出治疗数字：

```
+24
```

五个治疗数字固定在各自角色血条上方，不要全部挤在画面中央。

数字统一使用薄荷青，外围为白金光晕。

### 6. 余韵，约0.35秒

主要治疗结束后：

- 不再继续结算生命；
- 金色音符缓慢上升；
- 少量羽光和花瓣飘落；
- 地面法阵逐渐熄灭；
- 背景恢复正常亮度；
- 牧师缓缓落回原位。

最后响起一声较为悠长、但不刺耳的钟磬余音。

## 音效层次

可以使用四层音效：

1. 轻柔人声哼唱；
2. 空灵钟磬；
3. 低音弦乐铺底；
4. 治疗结算时的水晶扩散声。

不要加入爆炸声或剧烈低频震动。

## 镜头表现

- 开始时镜头缓慢拉远到98%，让全队进入画面；
- 日轮展开时恢复到100%；
- 治疗结算时进行一次柔和曝光提升；
- 不使用大幅度震屏；
- UI和行动条保持稳定。

## 总时长

正常速度约：

**1.25～1.5秒**

二倍速约：

**0.7～0.85秒**

# 六、神牧四个技能的视觉层级

|技能|视觉强度|建议时长|核心辨识点|
|---|---|---|---|
|惩击|中低|0.6秒|白金光矛、八芒日轮、技能点回流|
|快速治疗|中低|0.6秒|柔光带、莲瓣光环、单体抬血|
|能量灌注|中高|0.9秒|神圣冠冕、行动头像插入、增伤光环|
|神圣赞美诗|最高|1.4秒|大型日轮、全队光柱、群体治疗光波|

神圣赞美诗场面最大，但不依赖爆炸；能量灌注则是UI和战场联动最强的技能。

# 七、神牧技能按钮状态

## 惩击

正常状态：

- 白金色图标；
- 外圈保持较弱亮度。

使用后：

- 一枚小型金色光珠飞回技能点栏；
- 技能图标短暂出现“+1”光效。

## 快速治疗

当所有友方满血时：

- 技能按钮降低亮度；
- 悬停提示“当前没有需要治疗的目标”；
- 可以允许使用，但要提示可能产生过量治疗。

## 能量灌注

使用后按钮外围显示淡紫色残光。

若场上没有可行动的友方目标，按钮不可点击。

## 神圣赞美诗

技能点不足时：

- 日轮图标变为灰白；
- 外围三颗金色节点熄灭；
- 当技能点达到3点时，三个节点依次亮起。

# 八、治疗数字和血条规则

|反馈类型|颜色|表现|
|---|---|---|
|普通治疗|薄荷青|向上缓慢漂浮|
|强力治疗|亮青绿色＋金边|放大后回弹|
|群体治疗|统一淡青色|固定在各自角色上方|
|过量治疗|灰青色|尺寸较小|
|伤害提高|金色|附着于原伤害数字旁|
|立即行动|白金色|出现在行动条头像上|

治疗时血条应该：

```
当前生命
→ 出现半透明预计恢复区域
→ 生命值平滑填充
→ 显示最终数值
```

例如：

```
54/110
预计恢复到80/110
```

这样玩家在选择目标时就能提前判断技能价值。
